# 📚 BookSphere AI – Django Web Application

A web-based book management application developed using Python, Django, SQLite, HTML, CSS, JavaScript, and Pillow.

---

## 📌 Overview

BookSphere AI is a Django-based web application designed to manage book-related information through a web interface.

The application includes user authentication, book record management, and support for uploading book cover images and book files. Django handles the application logic and database interactions, while SQLite stores the application's data.

---

## ✨ Features

- 🔐 User registration
- 🔑 Login and logout functionality
- 📚 Book record management
- 🖼️ Book cover image uploads
- 📄 Book file uploads
- 🗄️ SQLite database integration
- 🌐 Browser-based user interface
- 🧩 Django-based application structure

2. Open the project directory.
3. Create and activate a Python virtual environment.
